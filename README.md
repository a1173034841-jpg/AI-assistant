# AI 主机厂售后洞察助手

## 项目定位

面向新能源主机厂区域运营和服务运营团队的 AI 车主服务体验洞察工具。

它将来自问卷、社群、App 评价、售后回访和活动反馈的车主原话，自动整理成服务环节归因、问题标签、情绪趋势、NPS 波动原因和行动建议。

## 项目价值

这个项目来自 Tesla 车主运营、移动服务口碑、NPS 分析和活动复盘经历，但产品定位不限定 Tesla，而是抽象为新能源行业通用的 VOC 洞察场景。

## MVP 形态

- Dashboard + AI 洞察报告
- 模拟多渠道反馈数据
- 规则标签体系 + LLM 分析
- React 本地原型
