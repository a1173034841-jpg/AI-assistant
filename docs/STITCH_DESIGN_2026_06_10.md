# 2026-06-10 售后复盘工作台 Design MD

范围：仅桌面端 Web 工作台。不要生成 mobile、phone、390px、移动底部导航、文档屏或历史版本说明页。

## 产品定位

产品全称：售后反馈连续复盘与分析工作台  
界面短名：售后复盘工作台

这是面向主机厂售后运营团队的反馈数据分析、复盘报告生成和数据问答工作台。它承接问卷星、腾讯问卷、App 问卷、短信链接、企微链接等渠道导出的售后反馈，把评分、时间、项目、区域、城市、服务中心和车主原话整理成可判断、可下钻、可复制、可查询、可推动闭环的运营材料。

所有新生成或新确认的桌面屏统一命名为：

`2026-06-10 - 界面名称 (Desktop)`

最终只保留 7 个目标状态参与产品交付：

1. `2026-06-10 - 工作台首页 / 最近工作区 (Desktop)`
2. `2026-06-10 - 新建项目 / 导入与校验 (Desktop)`
3. `2026-06-10 - 查看项目 (Desktop)`

## 信息架构

左侧导航是功能划分，不是工作流程。一级导航为：

1. 新建项目
2. 查看项目
3. 报告仪表盘
4. AI 问答
5. 个人中心

二级导航：

- 新建项目：上传反馈数据、字段映射、导入校验、生成初始复盘、导入历史
- 查看项目：全部项目、最近项目、项目详情、导入批次、归档项目
- 报告仪表盘：总览、时间维度、项目维度、区域维度、问题主题、报告输出
- AI 问答：新建问答、问答历史
- 个人中心：个人设置、账号状态、隐私设置、数据权限

默认首页态：用户刚进入网页、还没有点击任何一级导航时，右侧显示 `工作台首页 / 最近工作区`，二级导航完全隐藏。Hover 一级导航只能预览一级导航文字和说明，不能打开二级导航，不能刷新右侧主内容。只有 Click 一级导航后，才出现该一级下的二级导航，并进入该一级默认二级页面。

折叠态采用稳定 56px 一级图标栏 + 232px 浮层预览。预览只覆盖一级栏，不推动二级导航和主工作区，不允许闪烁、跳宽或按钮漂移。

点击二级导航后，右侧三级工作区必须完整刷新为该二级页面内容，不能只替换标题、右侧小卡片或局部说明。

## 品牌与 Logo

Logo 概念：声音 -> 证据 -> 决策。

结构：

- 深墨蓝 `#0F172A` 圆角方形外框，圆角 8px。
- 内部青绿色 `#008B8B` 对话气泡轮廓，表示车主反馈。
- 内部三根白色或浅青色 `#A7F3D0` 数据柱，表示反馈结构化和指标聚合。
- 右下小型通过勾 `#38A169`，表示校验通过、证据链和可追溯结论。

顶部栏主 Logo 44 x 44px，侧边栏 32 x 32px。不要 AI 星光、发光、渐变球、车辆剪影、复杂插画或剪贴板临时图标。

界面中不要出现：Agent、Stitch、Final 屏、历史版本、Precision Workbench、Dashboard 作为主入口、Projects / Templates、Supabase 数据接口。

## 视觉语言

整体是专业、克制、高密度的桌面运营控制台。

颜色：

- 背景：`#F8FAFC`
- 面板：`#FFFFFF` 或 `#F9FAFB`
- 结构色：`#0F172A`
- 主行动：`#008B8B`
- 风险：`#E53E3E`
- 需确认：`#DD6B20`
- 成功：`#38A169`
- 边框：`#E2E8F0`
- 次级文字：`#64748B`

禁止大面积渐变、AI 光效、营销 hero、装饰插画、手机端导航、嵌套卡片堆叠和过大圆角。卡片圆角不超过 8px。

## 排版与密度

- 页面标题：28-32px
- 区块标题：18-20px
- 正文和报告内容：15-16px
- 表格和列表：14-15px
- 证据原话：15px，行高不低于 23px
- 证据元信息：14px，行高不低于 20px
- 按钮 / chip / badge：14px
- 顶部全局信息：12px 标签 + 14px 数值

高密度应通过网格、对齐、分组实现，不是把字缩小。

## 网格与对齐

桌面主画布按 1440px 优化。

- 顶部栏：三段式网格，左侧 Logo / 产品短名，中间当前范围，右侧全局操作。
- 主体：左侧一级/二级导航 220-280px；主工作区 1fr；右侧辅助区 320-360px。
- 面板间距 16px 或 24px，面板内边距 20px 或 24px。
- 所有横向分栏页面必须在同一 grid 行内拉伸到同高。
- 左列、中列、右列顶部对齐、底部对齐。
- KPI 卡底边对齐，表格列宽稳定，数字列右对齐或使用等宽数字。
- 不允许大面积无意义空白。内容不足时，用历史、证据、查询结果、操作条或空状态补齐。
- 筛选器长字段拆成标题、元信息、数量三层显示，反馈量和时间范围不能挤成一团。

## 筛选逻辑

报告仪表盘筛选器做成横向、接近 Excel 的筛选形式，选择即应用，支持再次点击取消。

时间筛选必须是“粒度 + 具体周期”：

- 日：显示具体日期，例如 `2026-05-18`
- 周：显示具体周范围，例如 `2026-05-08 至 2026-05-14`
- 月：显示 `2026-05-01 至 2026-05-31`
- 季度：显示 `2026-04-01 至 2026-06-30`
- 年：显示 `2026-01-01 至 2026-12-31`
- 自定义：开始日期 + 结束日期输入，不允许伪装成固定快捷项

项目范围：全部项目、单项目、多项目、项目类型。每个项目必须显示名称、类型、时间范围和反馈量。

区域层级：区域是父级，城市是区域子级，服务中心是城市子级。未选区域时城市提示“先选区域”；未选城市时服务中心提示“先选城市”。切换上级时自动清除不合法下级。服务中心选中后立即应用，不再做重复“服务中心下钻”。

下一步：进入报告输出时按当前筛选范围生成报告；进入 AI 问答时带入当前筛选范围；从左侧直接进入 AI 问答时默认自由新问答。

## AI 问答

AI 问答默认进入新建问答，同时展示问答历史。

布局：左侧问答历史，中间主对话和大输入框，右侧本次回答引用证据与操作。中间聊天区必须明显宽于左右辅助栏，输入区要适合连续输入。

必须支持：新建对话、套用当前筛选范围、参考项目选择和取消、历史记录打开和关闭、推荐问题填入输入框、发送查询、问答收藏星标、保存当前问答、生成问答摘要。

发送后展示流程：整理范围 -> 查找证据 -> 生成结论 -> 保存记录。

无关问题自然拒答：`这个问题超出了当前售后反馈数据范围，我只能回答已导入数据、指标、报告结论和反馈原文相关问题。`

## 证据原话

证据原话不是左侧二级导航，也不是筛选入口。它只出现在报告输出、指标详情、风险对象详情和 AI 问答结果中，用来支撑结论。

证据卡必须展示：原话内容、评分 / NPS、提交时间、来源平台、城市 / 服务中心、服务场景、入选原因。左侧 3-4px 状态色条，元信息使用两列网格，不能压缩成灰色小字。

## 页面重点

### 工作台首页 / 最近工作区

默认未点击一级导航时显示。二级导航隐藏。展示最近项目、待处理导入、近期报告、可继续问答和最近工作入口。

### 新建项目 / 导入与校验

展示 Excel / CSV 上传、标准模板下载、项目识别、字段映射、必填字段完整性、指标覆盖率、隐私字段检查、历史导入和校验状态。上传区、字段映射、识别结果三列顶部和底部对齐。

### 查看项目

展示全部项目、最近项目、项目详情、导入批次、归档项目。项目卡片和表格行可点击、可再次点击取消。选中项目后才出现“打开报告仪表盘”动作。

### 报告仪表盘 / 筛选与维度下钻

包含横向筛选区、指标区、风险表格、当前范围、下一步动作和浮动 AI 问答入口。筛选区、指标区、右侧范围面板同高对齐。

### 报告仪表盘 / 报告与专项输出

总复盘报告优先。专项入口包括：服务问题闭环、满意度归因、区域城市督查端、活动体验复盘、口碑投诉与风险。专项入口必须有选中态，点击后报告摘要和右侧内容同步变化。

### AI 问答

标题使用 `AI 问答`。按钮使用 `发送查询`。回答区叫 `数据查询结果`。不要出现装饰性证据卡，右侧证据必须和当前回答相关。

### 个人中心

只承载个人设置、账号状态、隐私设置、数据权限、导入历史摘要和问答记录摘要。不显示 `Supabase 数据接口` 或任何具体后端平台内部模块。
