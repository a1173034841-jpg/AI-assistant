# MVP 范围

## 1. MVP 目标

MVP 要证明：第三方问卷、App 问卷或短信链接收集到的售后反馈，可以被运营团队按项目和日期导入，快速得到一份有结论、有证据、有动作、有原始评论可追溯的服务复盘报告。

核心链路：

```txt
问卷 Excel / CSV 导出
-> 识别项目、时间、字段映射
-> 指定项目和日期范围
-> 查看重点关注、建议报告和专项指标
-> 下钻区域 / 城市 / 服务中心
-> 展开原始评论和分数来源
-> 复制总报告或专项报告
```

工作台采用步骤式向导，而不是三栏信息同时展开。运营按“选项目 -> 定范围 -> 看诊断 -> 拿输出”推进，并且每一步都能回退修改。

## 2. 必须做

### 问卷字段页

- 展示可放到问卷星、腾讯问卷、App 问卷里的字段建议。
- 说明每个字段后续如何进入分析：服务评分、推荐意愿评分、城市、服务中心、服务场景、开放反馈、授权联系。
- 说明填写率优化策略：低摩擦、服务后及时触达、自动带入上下文、轻提醒。

### 导入与识别

- 首版用模拟 Excel / CSV 批次表示真实导入。
- 业务项目和问卷来源分开：项目是分析对象，问卷星、腾讯问卷、App 内问卷是来源通道。
- 同一业务项目可以合并多份来源文件，例如一个“五一售后服务专项”同时包含问卷星导出和 App 内问卷导出。
- 提供标准导入模板，至少包含项目名称、问卷来源、提交时间、区域、城市、服务中心、服务场景、服务评分、推荐意愿评分 和开放反馈原话。
- 导入后需要确认：
  - 项目名称：优先读表格中的项目 / 活动 / 问卷名称列，没有则用文件名建议。
  - 时间范围：根据提交时间列自动取最早和最晚日期。
  - 字段映射：城市、服务中心、服务评分、推荐意愿评分、开放反馈、服务场景。
- 不做真实第三方 API 对接。

### 运营工作台

- 支持项目批次选择。
- 支持开始日期、结束日期筛选。
- 支持区域、城市、服务中心下钻。
- 支持服务中心原始评论展开，按提交时间倒序排列。
- 指标必须说明分数来源，不能只显示数字。
- 原型需包含千级样本项目，用于验证一周几百到几千条反馈的聚合、筛选和代表样本展示。
- 大样本不默认铺开全部原话，只展示聚合指标、下钻范围和代表证据。

### 重点关注

- 单独展示做得好的服务区域 / 服务中心。
- 单独展示做得差的服务区域 / 服务中心。
- 提炼典型共性、代表样本、建议动作和证据原话。

### 报告与专项分析

- 先给总报告，再给专项报告。
- 总报告不能是分报告合集，需要回答：
  - 本期先处理哪里？
  - 体验下降主因是什么？
  - 哪些动作下周要追？
  - 哪些正向样本可以复制？
- 服务问题闭环不是第二份总报告，而是服务运营待办清单，需要包含处理对象、问题、证据、责任动作、时限和回访口径。
- 专项下钻包括：
  - 服务问题闭环
  - 满意度归因
  - 区域 / 城市下钻
  - 活动体验复盘
  - 口碑素材与风险

### 指标维度

- 反馈量
- 平均评分
- NPS
- 推荐者 / 贬损者
- 被动者
- 满意率
- 低分反馈
- 负向占比
- 待跟进
- 联系授权率
- 需人工复核
- 风险服务中心
- 高发服务环节

## 3. 明确不做

- 不自研完整问卷创建器。
- 不做复杂题型、跳题逻辑和问卷投放系统。
- 不接问卷星 / 腾讯问卷 API。
- 不做登录、权限、数据库、历史报告库。
- 不处理真实姓名、手机号、车牌、VIN 或住址。
- 不输出维修诊断或安全驾驶建议。
- 不把 Dashboard 作为 MVP 主入口。
- 不把提效比例作为运营用户界面卖点。

## 4. MVP 页面

### 页面一：问卷字段说明

用于说明用户端反馈如何被第三方问卷平台低摩擦收集，以及字段如何进入后续分析。

核心内容：

- 问卷字段预览
- 字段必填 / 可选说明
- 字段后续用途
- 填写率优化提示
- 隐私和授权提示

### 页面二：售后反馈报告工作台

用于展示运营如何把问卷结果变成可用报告。

核心步骤：

1. 选择业务项目和来源文件。
2. 设定时间与地区范围。
3. 查看诊断结论、重点关注和指标解释。
4. 选择专项输出，复制总报告或专项清单。

回退逻辑：

- 顶部步骤可直接跳回项目、范围、诊断或输出。
- 底部提供上一步 / 下一步。
- 诊断页提供修改项目、修改时间 / 地区。
- 输出页提供返回诊断、修改范围。

## 5. 成功标准

- 运营用户能按项目和日期得到一份清晰报告。
- 能选择千级样本项目并完成聚合分析，页面不因原话数量增加而失控。
- 报告结论能展开证据原话。
- 每个分数能解释来源。
- 能看到做得好的区域和做得差的区域的共性。
- 能下钻到城市、服务中心和原始评论。
- 输出内容能复制到周报、复盘会材料或服务中心跟进清单。
