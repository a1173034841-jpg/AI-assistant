# 五套售后问卷模板确认稿

本文件用于确认五类售后服务问卷结构。确认后，下一轮基于这些模板生成约 500 份完整模拟答卷，并进入清洗、去重、Chunk、切词和向量入库准备。

所有问卷均模拟问卷星 / 腾讯问卷导出结构。所有用户、手机号、车牌、VIN 均为透明假数据，并在生成后使用 Microsoft Presidio 扫描和脱敏校验。

## 3. 问卷一：质量维保型

### 定位

用于收集维修质量、保养体验、问题复发、配件等待、交付质量和闭环处理反馈。建议 21 题。

| 序号 | 题目 | 题型 | 采集目的 |
| ---: | --- | --- | --- |
| Q1 | 本次维保服务类型是？ | 单选 | 区分保养、维修、检测、返修 |
| Q2 | 本次进店或上门前，问题描述是否被准确记录？ | 单选 | 服务发起质量 |
| Q3 | 服务顾问是否清楚解释检查或维修方案？ | 1-5 分 | 沟通解释 |
| Q4 | 本次维修或保养是否在承诺时间内完成？ | 单选 | 履约时效 |
| Q5 | 是否出现配件等待或缺件情况？ | 单选 | 配件问题 |
| Q6 | 交付车辆时，服务人员是否说明维修/保养结果？ | 1-5 分 | 交付解释 |
| Q7 | 本次处理后，原问题是否仍然存在或复发？ | 单选 | 问题复发 |
| Q8 | 如果问题未解决或复发，请描述具体表现。 | 开放题 | 质量证据 |
| Q9 | 您对维修/保养结果的满意度是？ | 1-5 分 | 质量满意 |
| Q10 | 您对费用说明或保修政策解释是否清楚？ | 1-5 分 | 费用/保修理解 |
| Q11 | 服务过程中是否出现新增损伤、遗漏项目或交付瑕疵？ | 单选 | 高风险事件 |
| Q12 | 如有新增损伤、遗漏或交付瑕疵，请描述。 | 开放题 | 风险原话 |
| Q13 | 您认为本次最需要改进的环节是？ | 多选 | 问题标签 |
| Q14 | 本次服务是否需要售后进一步回访？ | 单选 | 闭环信号 |
| Q15 | 您愿意给本次服务中心留下正向评价吗？ | 单选 | 口碑素材 |
| Q16 | 如果愿意，请写下可用于内部表扬的具体原因。 | 开放题 | 正向证据 |

| Q18 | 通用 B2：服务中心 | 下拉 | service_center |
| Q19 | 通用 B4：总体评分 | 评分 | rating |
| Q20 | 通用 B5：推荐意愿评分 | 评分 | nps_score |
| Q21 | 通用 B7/B8：是否愿意联系及一句话反馈 | 单选+开放 | contact / feedback_text |

### 重点字段

- `service_stage` 优先映射到服务质量、服务接待、服务发起。
- `issue_tags` 覆盖维修结果、配件等待、问题复发、交付体验、费用解释。
- 负向高严重度样本进入闭环清单。

| Q3 | 您给出该推荐分数的主要原因是什么？ | 开放题 | 推荐/贬损原因 |
| Q4 | 哪些因素最影响您本次评分？ | 多选 | 归因标签 |
| Q5 | 本次服务中最满意的环节是？ | 单选 | 正向环节 |
| Q6 | 本次服务中最不满意的环节是？ | 单选 | 负向环节 |
| Q7 | 服务人员态度是否符合预期？ | 1-5 分 | 接待评价 |
| Q8 | 服务响应速度是否符合预期？ | 1-5 分 | 效率评价 |
| Q9 | 费用、权益或政策说明是否清楚？ | 1-5 分 | 解释清晰度 |

| Q11 | 您是否感到本次服务比上次更好？ | 单选 | 趋势感知 |
| Q12 | 如有变化，请说明变好或变差的原因。 | 开放题 | 对比证据 |
| Q13 | 您是否愿意继续选择该服务中心？ | 单选 | 留存意向 |
| Q14 | 如果只能改进一件事，您希望优先改进什么？ | 开放题 | 动作建议 |

### 重点字段

- `nps_score` 用于推荐者、被动者、贬损者结构。
- `rating` 用于满意率、低分反馈、平均评分。
- 开放题用于解释指标变化，不允许生成无证据结论。
