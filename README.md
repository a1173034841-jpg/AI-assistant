# 主机厂售后运营文本工作台

## 项目定位

面向新能源主机厂售后运营团队的 AI 文本工作台。

它不替代问卷星、腾讯问卷、App 问卷或售后回访系统，而是承接这些渠道收集到的车主原话，把零散反馈整理成运营团队能直接使用的复盘简报、问题清单、口碑素材和风险摘要。

用一句简单的话说：

> 问卷负责把车主声音收进来，这个工具负责把车主声音变成运营能用的材料。

## 产品故事

车主完成售后服务后，主机厂通常会通过问卷星、腾讯问卷、App 内问卷、短信或企微链接收集反馈。现实问题是：车主不一定愿意填；即便填了，运营团队拿到的也常常是一批零散原话。

这些原话里有抱怨、有建议、有表扬、有情绪、有具体服务问题，但它们不能直接进入周报、复盘会、服务中心改进或口碑传播。

本项目要做的是中间这一层加工能力：把第三方问卷或其他触点收集到的反馈导入报告工作台，按项目和日期范围生成总报告、重点关注、专项复盘、证据原话和可追溯的原始评论。

## MVP 形态

- 第三方问卷结果承接：按问卷星、腾讯问卷、App 问卷导出的 Excel / CSV 设计。
- 售后反馈问卷字段：提供字段建议、字段用途和填写率优化策略，不自研完整问卷系统。
- 售后反馈报告工作台：项目识别、日期筛选、重点关注、专项分析、原始评论下钻。
- 场景化产物：总报告、服务问题闭环、满意度归因、区域 / 城市下钻、活动复盘、口碑素材与风险。

## 当前阶段

当前处于网页原型与 MVP 补齐阶段。

已经有本地 React 原型和模拟数据；下一步需要补真实 Excel / CSV 解析、字段映射确认、大样本评论分页和报告导出。
